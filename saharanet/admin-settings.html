Adding a New Admin

For security, new admin accounts can't be created from a public form. To add a new admin:

  1. Ask the person to sign up as a regular customer first (or create the user manually from Supabase → Authentication → Users).
  2. Copy their User UID from the Supabase Authentication panel.
  3. Insert a row into the admin table with that user_id, their name, email, department, and a role_id from admin_roles.
